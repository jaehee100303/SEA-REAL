# SEA-REAL (시리얼)

> 바가지 걱정 없는 부산 여행, 믿을 수 있는 가격과 현지 경험을 한 곳에서.

SEA-REAL은 부산을 방문하는 국내외 관광객을 위한 바다 관광 플랫폼 V1 프로토타입입니다.

## 주요 기능

- 부산 주요 시장의 수산물 시세 비교
- 해수욕장 주변 맛집 Google Maps 검색
- 블루리본 추천 맛집 지도 연결
- 부산 로컬 사전과 Taste Navigator
- 다국어 화면 및 환율 편의 기능

## 웹사이트

GitHub Pages 자동 배포를 사용합니다.

## 프로젝트 상태

현재 버전은 출시 실험 모델 V1입니다.
